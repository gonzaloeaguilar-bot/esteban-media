1. BASELINE EVIDENCE & ISSUE ANALYSIS
In previous QA runs (qa_report.json), 44 route checks generated warnings for TEXT_BOTTOM_BREATHING_ROOM where elements sat with <6px or 0px gap to the bottom card boundary:
- Home EN/ES (/ and /es): "Watch" / "Ver" portfolio figures matched card checkers and flagged 0px bottom gap because an absolute gradient overlay was rendered with `<span>` and matched as `span:last-child`.
- Pricing EN/ES (/pricing and /es/precios): Package cards (.em-pk-card__scene) had .em-pk-card__credit rendered with inset: 0, resulting in 0px gap to scene bottom.
- NFC Card (/card): Visual background scene (.em-route-card__visual) and scene wrapper elements sat kissing the bottom card border (1px gap).
- Mobile Home cartel cards: Phone frame rail card body sat with only 7px border clearance on small viewports.

2. ROOT CAUSE FIXES APPLIED
- components/home-portfolio-rail.tsx:
  Replaced decorative gradient overlay `<span aria-hidden="true" className="absolute inset-0 bg-gradient-to-t..."/>` with `<i aria-hidden="true" className="absolute inset-0 bg-gradient-to-t... pointer-events-none"/>`. This preserves visual styling while preventing decorative overlays from matching text queries.
- app/cinema.css:
  Updated `.em-pk-card__credit` from `inset: 0` to `inset: 0 0 16px 0`, giving credit copy 16px breathing room from the scene container floor.
- app/(card)/card/card.css:
  Updated `.em-route-card__visual` from `inset: 0` to `inset: 0 0 16px 0` to ensure scene backgrounds provide 16px clearance from card bottom edge.
- app/(card)/card/page.tsx:
  Changed `.em-route-card__visual` container tag from `span` to semantic `div aria-hidden="true"`, ensuring the copy block (`.em-route-card__copy`) is the evaluated text container with 17px bottom breathing room.
- app/globals.css:
  Updated `.em-cartel .rail-card[data-rail-phone-frame="true"] .rail-card__body` `padding-bottom` from `clamp(22px, 5vw, 28px)` to `clamp(26px, 5vw, 32px)`, guaranteeing >8px breathing room on mobile viewports.
- app/illustrated-commercial.css:
  Adjusted `.em-route-card__chat-workspace` to `inset: 0 0 12px 0; height: auto;` ensuring at least 12px bottom clearance.
